# PIC18F4580 Embedded Systems Projects

A collection of hands-on Embedded C projects developed using the PIC18F4580 microcontroller and simulated using Proteus.

This repository documents my learning and practical implementation of PIC18F4580 peripherals, digital interfaces, and communication modules.

## Projects

| No. | Project | Concepts |
|---|---|---|
| 01 | LED Blink | GPIO, Digital Output |
| 02 | Switch LED | Digital Input/Output |
| 03 | LED Patterns | GPIO, Logic & Patterns |
| 04 | 7-Segment Display | Display Interfacing |
| 05 | Keypad | 4×4 Keypad Interfacing |
| 06 | LCD 16×2 | LCD Interfacing |
| 07 | DC Motor | Motor Control |
| 08 | Timers | Timer0, Timer1, Timer2 & Timer3 |
| 09 | ADC + LCD | Analog-to-Digital Conversion |
| 10 | PWM | CCP1 & Timer2 |
| 11 | UART | EUSART, Transmission & Interrupt-Based Reception |
